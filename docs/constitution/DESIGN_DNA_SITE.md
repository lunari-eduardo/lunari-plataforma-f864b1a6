# Design_DNA_SITE
Versão 1.0

## Filosofia

O site do Lunari não deve parecer uma landing page tradicional de SaaS.

Também não deve parecer um catálogo de funcionalidades.

Cada seção deve parecer um capítulo de uma mesma história.

Muito espaço negativo.
Poucos elementos.
Tipografia protagonista.
Imagens e vídeos com função narrativa.

O design transmite maturidade, calma e confiança.

Jamais excesso.

---

## Ritmo das seções

Alternar sempre:

Escuro → Claro → Escuro → Claro

Cada mudança de cor representa um novo capítulo.

Nunca utilizar duas seções consecutivas com o mesmo fundo — exceção narrativa: quando duas seções formam um mesmo capítulo (ex.: Seção 02 e 03 da Home), o fundo se mantém e a mudança acontece pelo conteúdo.

---

## Layout

Todas as seções utilizam layout dividido.

### Desktop

- 40~45% conteúdo
- 55~60% elemento visual

Alternância obrigatória:

- Seção 01 — texto à esquerda, visual à direita
- Seção 02 — visual à esquerda, texto à direita
- Seção 03 — texto à esquerda, visual à direita
- ...

### Mobile

Sempre: texto → visual. Nunca inverter essa ordem.

---

## Vídeos

Utilizar vídeos apenas nas Hero Pages: Home, Studio, Gallery Select, Gallery Transfer.

Máximo de quatro vídeos em todo o site.

Os vídeos não explicam funcionalidades. Criam atmosfera e reforçam o posicionamento do produto.

Devem lembrar um comercial de produto premium: movimentos lentos, macro, mudança de foco, profundidade de campo.

Nenhuma captura de tela. Nenhum tutorial.

---

## Imagens

As imagens devem parecer editoriais.

- Nunca bancos de imagens.
- Nunca pessoas sorrindo olhando para notebooks.
- Nunca mockups genéricos.

Sempre composições elegantes relacionadas ao universo fotográfico: fotografia fine art, materiais nobres, papel, luz natural, objetos cuidadosamente posicionados.

As imagens devem transmitir sensação, não explicar funcionalidades.

---

## Tipografia

Grandes títulos. Poucas palavras. Muito respiro.

Nenhum bloco grande de texto.

A copy sempre conduz o olhar antes do elemento visual.

---

## Cores

Tema oficial: Silent Luxury.

- Escuro `#0B0B0B`
- Claro `#F7F5F2`
- Dourado fosco `#C9A87C` — único acento, apenas para detalhes e destaques.

Nunca utilizar terracota nem qualquer outra cor de acento. Nunca utilizar grandes áreas coloridas.


---

## Elementos visuais

Sem glassmorphism. Sem gradientes exagerados. Sem neon. Sem cards decorativos. Sem caixas apenas para preencher espaço. Sem linhas conectando elementos. Sem infográficos.

Todo elemento deve possuir função narrativa.

---

## Movimento

Animações discretas: fade, translate suave, pequeno parallax.

Nada depende do scroll para ser compreendido. O usuário nunca deve precisar "ativar" uma animação para entender uma seção.

---

## Linguagem

A Home desperta interesse. As páginas Studio, Gallery Select e Gallery Transfer aprofundam.

Nenhuma seção tenta explicar o sistema inteiro. Cada página responde apenas uma pergunta.

---

## Regra de ouro

Antes de adicionar qualquer elemento visual, responder:

"Este elemento comunica alguma ideia ou apenas ocupa espaço?"

Se apenas ocupar espaço, ele não pertence ao site.
